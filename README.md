# 🐜 Ant Colony Foraging Simulation

A Multi-Agent System (MAS) simulation built with Python
that demonstrates how ants find food using pheromone 
trails — with no central control.

## 🧠 AI Concepts Demonstrated
- Autonomous Agents
- Agent Perception & Actions
- Stigmergy (indirect communication)
- Emergent Collective Intelligence
- State Machine (searching / carrying)

## ▶️ How to Run
1. Make sure Python is installed
2. Open ant_colony_tkinter.py in PyCharm
3. Press Play — no installation needed!

## 🎮 Controls
- Pause/Resume button — freeze the simulation
- Reset button — restart with fresh food and ants

## 🛠️ Built With
- Python (Tkinter)
- No external libraries needed!
